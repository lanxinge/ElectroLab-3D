# ElectroLab 3D 品牌标识

标识把字母 **E** 与电路走线、连接端点结合，折叠的线条呼应 3D 实验台。深蓝底色与青蓝走线延续产品界面配色。

## 文件与用途

| 文件 | 建议用途 |
|---|---|
| `public/brand/electrolab-logo.png` | 原始高清透明 PNG，README、文档、封面 |
| `public/brand/electrolab-icon.webp` | 256 × 256 网页图标，导航栏与首页 |
| `public/brand/favicon.png` | 48 × 48 浏览器图标 |

等比例缩放，保留透明外边距；不要拉伸图形。小尺寸优先使用图形本身，产品名称由正常字体单独排版。

主色：深蓝 `#0B1425`、青色 `#70DEEE`、电蓝 `#319CEB`。
