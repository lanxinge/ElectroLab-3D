# ElectroLab 3D 使用指南

## 1. 打开实验室

安装 Node.js 24 后，Windows 双击 `start.cmd`；macOS / Linux 在项目目录运行 `sh start.sh`。

首次启动自动安装依赖并构建，浏览器在服务就绪后打开。默认网址为 http://127.0.0.1:3001；启动窗口用于保持服务运行，按 Ctrl+C 可停止。

## 2. 首页与课程

- **开始第一课／继续学习**：进入课程或回到上次步骤。
- **精选实验**：直接体验 RC、NE555、DAC。
- **上册／下册**：按电路基础、模电数电浏览课程。
- **自由实验台**：继续当前工作台中的电路。
- **项目库**：打开本地工程或账号中保存的项目。

学习位置与完成记录保存在当前浏览器。进入课程后，先读目标、预测变化，再调参数，并用实时读数和波形检验预测。

## 3. 搭建电路

1. 从面板菜单或悬浮入口打开元件库。
2. 添加元件，拖动调整位置。
3. 点击引脚，再点击目标引脚完成接线。
4. 选择元件，打开属性修改阻值、电压、开关状态等参数。
5. 打开实时分析区查看电压、电流、功耗和状态。

三维视图支持右键旋转、滚轮缩放，也可切换俯视和正视。复杂电路可先使用纯 2D；教学中的“自动视图”会根据规模选择布局。

## 4. 暂停、单步与示波器

- **运行／暂停**：连续观察，或停下读取瞬时状态。
- **单步**：推进一个仿真微步，适合观察暂态。
- **时间倍率**：降低速度，观察短脉冲与换路过程。
- **+CH**：将测量结果加入示波器，最多四个通道。
- **清空波形**：重新开始收集显示数据。

电压与电流通道采用对应的单位。交流页还显示有效值、平均有功、视在功率与功率因数。

## 5. 理解当前元件

选中元件后点击“思索”，或从课程内打开原理演示。

- **标准原理演示**：用标准例子认识器件。
- **解释当前元件**：带入当前参数和读数解释状态。

可切换演示章节、调整演示参数，并与工作台中的结果对照。

## 6. 教学与自由实验之间切换

“本关已完成”保存学习记录，“当前实验状态”反映此刻是否满足实验条件。通关后继续调节参数，已完成记录会保留。

- **返回自由仿真台**：恢复进入教学前的原实验，包括暂停状态、仿真时间和示波缓存。
- **带电路去自由台**：将当前课程电路留在工作台继续设计。

## 7. 保存、导入与复用

顶栏和项目库均支持导出 `.elab.json`，也可导入旧版 `.json` 网表。工程文件包含结构、参数和封装内容；打开后重新开始仿真。

登录后，可在项目库将当前电路另存到账号。配置 IC 输入／输出边界后，还可以封装子电路供后续设计复用。

## 8. 常见启动问题

| 现象 | 操作 |
|---|---|
| 提示找不到 Node.js | 安装 Node.js 24，重新打开启动文件 |
| 默认端口被占用 | 使用 `start.cmd --port 3002` 或 `sh start.sh --port 3002` |
| 浏览器未自动打开 | 手动访问启动窗口显示的网址 |
| 安装依赖中断 | 保持联网后再次运行启动文件 |
| 更新后仍显示旧界面 | 使用 `--rebuild` 启动，再刷新浏览器 |
| 想只准备环境 | 使用 `--setup-only` 安装并构建 |

## 9. 本机配置

根目录 `.env` 保存本机配置，一键脚本会自动创建必要内容。可以设置 `PORT`、`DB_PATH` 和 `JWT_SECRET`；示例见根目录 `.env.example`。

默认数据文件是 `data/electrolab.sqlite`。工程数据和本机配置均不纳入 Git 提交。
